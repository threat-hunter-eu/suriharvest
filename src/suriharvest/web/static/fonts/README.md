# Bundled UI fonts

Retrieved 2026-11-16 from [google/fonts](https://github.com/google/fonts) (`ofl/`). Fonts are served locally; no browser
CDN requests. Each file is a Latin subset of the upstream variable font, converted to WOFF2 with fontTools (weight
range trimmed to what the UI uses). The upstream SIL Open Font License texts are included beside the fonts.

Atkinson Hyperlegible Next is the text face, Atkinson Hyperlegible Mono the code face (rules, queries, hashes) and
Archivo, set semi-expanded, the display face (page titles, the big numbers, the wordmark).
